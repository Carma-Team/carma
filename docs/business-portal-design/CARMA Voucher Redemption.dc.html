Voucher Redemption

מימוש הטבה — the point-of-sale flow a business employee runs while a customer waits at the counter. Scan or type a code, review what's about to be given, confirm once, done. Validation never consumes the voucher; only an explicit confirm does. The driver's identity never appears.

Flagged, not built. Capabilities noticed while designing this but out of scope this round — see the box below the flow.
Frames are 1440×900. Out of scope: redemption history, analytics, dashboard, employees, settings.

Assumptions

Lookup is synchronous and online; the code/QR resolves to one voucher in under a second in the happy path.
The manual code is short, alphanumeric, case-insensitive, dash-tolerant — typeable without a reference sheet.
A voucher already scopes to this business — "wrong business" is a validation outcome, not a filter the employee sets.
Confirm is a lightweight modal over the details screen, not a page transition — keeps the flow to one visual context.
Camera access can be denied or absent; manual entry is a first-class sibling, not a fallback link.

Error & edge states

Every state replaces the review card in frame 04 — same shell, same 520px card. Color plus icon plus a plain-language sentence; never color alone. Each names the next step. "Unknown code" and "belongs to another business" are intentionally the same neutral state below — the backend never reveals which case occurred. "פורמט קוד לא תקין" is a local pre-lookup check only; any lookup sent to the backend that can't resolve returns the neutral state. "ניסיון מימוש חוזר" is a UX-level guard against a double click/scan, not a distinct backend outcome — a repeat lookup after real redemption surfaces as "השובר כבר מומש".

לא ניתן לאמת את השובר
הקוד אינו תקין או שאינו זמין למימוש בבית העסק הזה. בדקו את הקוד ונסו שוב.
השובר כבר מומש
השובר הזה כבר מומש בעבר ולא ניתן לממש אותו שוב. מומש לפני 3 ימים.
השובר פג תוקף
תוקף השובר הסתיים ב-14 באוג׳ 2026 ולא ניתן לממש אותו.
פורמט קוד לא תקין
מה שהוזן לא יכול להיות קוד שובר תקין (אורך/תווים). בדקו את הקוד המוצג ללקוח.
שגיאת תקשורת
לא ניתן להתחבר לשרת כרגע. בדקו את החיבור לאינטרנט ונסו שוב.
המימוש נכשל
הבדיקה עברה בהצלחה אך המימוש נכשל. השובר לא נצרך — אפשר לנסות שוב.
ניסיון מימוש חוזר
זוהתה לחיצה כפולה על מימוש. אם השובר כבר נצרך, הבדיקה הבאה תוצג כ"השובר כבר מומש".
